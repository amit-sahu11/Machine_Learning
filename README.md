# Machine Learning Notebooks

A collection of Jupyter notebooks exploring core Machine Learning algorithms, concepts, and real-world datasets - built with Python's most popular data science libraries.

## Topics Covered

| Category | Algorithms / Concepts |
|---|---|
| Supervised Learning | Linear Regression, Logistic Regression, Decision Trees, SVM, KNN |
| Unsupervised Learning | K-Means Clustering, PCA |
| Ensemble Methods | Random Forest, Gradient Boosting |
| Model Evaluation | Confusion Matrix, ROC Curve, Cross-Validation |
| Feature Engineering | Scaling, Encoding, Missing Data Handling |
| Data Visualization | Matplotlib, Seaborn plots |

## Tech Stack

- Python 3.x
- - Jupyter Notebook
  - - NumPy and Pandas
    - - Scikit-learn
      - - Matplotlib and Seaborn
       
        - ## Getting Started
       
        - ```bash
          # Install dependencies
          pip install numpy pandas scikit-learn matplotlib seaborn jupyter

          # Launch Jupyter
          jupyter notebook
          ```
